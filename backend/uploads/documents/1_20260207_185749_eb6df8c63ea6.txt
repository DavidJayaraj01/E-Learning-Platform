Introduction to Python Programming

Chapter 1: Getting Started with Python

Python is a high-level, interpreted programming language known for its simplicity and readability. 
It was created by Guido van Rossum and first released in 1991. Python's design philosophy 
emphasizes code readability with its use of significant whitespace.

Python supports multiple programming paradigms, including procedural, object-oriented, and 
functional programming. It has a comprehensive standard library and a large ecosystem of 
third-party packages available through PyPI.

Key features of Python include:
- Easy to learn syntax
- Interpreted language (no compilation needed)
- Dynamic typing
- Automatic memory management
- Large standard library

Chapter 2: Variables and Data Types

In Python, variables are containers for storing data values. Unlike other programming languages, 
Python has no command for declaring a variable. A variable is created the moment you first 
assign a value to it.

Python has several built-in data types:
- Integers (int): Whole numbers like 1, 42, -7
- Floating-point (float): Decimal numbers like 3.14, -0.5
- Strings (str): Text enclosed in quotes like "Hello"
- Boolean (bool): True or False values
- Lists: Ordered, mutable collections
- Tuples: Ordered, immutable collections
- Dictionaries: Key-value pairs

Chapter 3: Control Flow

Control flow statements allow you to control the execution order of your code.

If statements are used for conditional execution:
if condition:
    # do something
elif other_condition:
    # do something else
else:
    # fallback

Loops are used for iteration:
- For loops iterate over sequences
- While loops continue until a condition is false

Chapter 4: Functions

Functions are reusable blocks of code that perform a specific task. They help in organizing 
code and making it more modular and maintainable.

def greet(name):
    return f"Hello, {name}!"

Functions can have parameters, default values, and return values. Python also supports 
lambda functions for creating anonymous functions.
